> _If any detail here contradicts the code, trust the code — not this page._

This section is the entry point for generated API material. Endpoint-level facts should come from generated OpenAPI pages, not handwritten summaries.

Auth Service and ML Service OpenAPI sidebars are generated by `npm run prepare:docs`. If those generated directories are absent, the sidebar loader skips them during a plain `npm run build`.

## Runtime Boundaries

- Auth routes are served by Auth Service under `/api/auth`.
- Core product routes are served by Core API under `/api/*`.
- SignalR hubs are `/chatHub` and `/notificationHub`.
- ML Service exposes FastAPI routes internally and through frontend proxy paths where applicable.

## Regeneration

Use the portal preparation pipeline to refresh generated API pages:

```bash
cd documentation
npm run prepare:docs
```

Then build the Docusaurus site:

```bash
npm run build
```

## Handwritten Endpoint Audit

The documentation pages under `documentation/docs/` were checked against route attributes in `DevHunt.CoreApi/Controllers`, `DevHunt.AuthService/Controllers`, and the minimal CSRF endpoints registered in each service `Program.cs`.

| Endpoint or path documented                   | Verified implementation                                                       | Status                                                            |
| --------------------------------------------- | ----------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| `GET /api/auth/me`                            | `DevHunt.AuthService.Controllers.AuthController.GetCurrentUser`               | Matches Auth Service controller.                                  |
| `GET /api/auth/csrf-token`                    | Minimal endpoint in `DevHunt.AuthService/Program.cs`                          | Exists outside the controller set.                                |
| `GET /api/auth/callback/{provider}`           | `DevHunt.AuthService.Controllers.AuthController.ExternalCallback`             | Matches Auth Service controller for Google/GitHub callback paths. |
| `GET /api/profile/me`                         | `DevHunt.CoreApi.Controllers.ProfileController.GetMyProfile`                  | Matches Core API controller.                                      |
| `GET /api/projects`                           | `DevHunt.CoreApi.Controllers.ProjectsController.GetProjects`                  | Matches Core API controller.                                      |
| `POST /api/notifications/mark-read/{id:guid}` | `DevHunt.CoreApi.Controllers.NotificationsController.MarkRead`                | Current persisted Core API read route.                            |
| `POST /api/notifications/mark-all-read`       | `DevHunt.CoreApi.Controllers.NotificationsController.MarkAllRead`             | Current persisted Core API bulk-read route.                       |
| `/chatHub`                                    | `DevHunt.CoreApi.Hubs.ChatHub` mapped in `DevHunt.CoreApi/Program.cs`         | SignalR hub, not a controller action.                             |
| `/notificationHub`                            | `DevHunt.CoreApi.Hubs.NotificationHub` mapped in `DevHunt.CoreApi/Program.cs` | SignalR hub, not a controller action.                             |
| `/api/proxy-core/*`, `/api/proxy-auth/*`      | Frontend rewrites in `frontend/next.config.mjs`                               | Frontend proxy paths, not backend controller routes.              |
| `/api/proxy-ml/*`                             | Frontend ML proxy route handler                                               | Frontend route handler, not a Core/Auth controller route.         |

:::warning Outdated
Generated OpenAPI pages can be stale until `npm run prepare:docs` is rerun. If a generated page and a controller route attribute disagree, the controller route attribute is the source of truth.
:::
