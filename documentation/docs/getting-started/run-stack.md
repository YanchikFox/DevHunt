# Running the Stack

Reference for common `docker compose` operations after the initial setup in [Quickstart](./quickstart).

> _If any detail here contradicts the code, trust the code — not this page._

## Full stack

```bash
docker compose up -d
```

Brings up all services. `db-migrator` runs migrations and exits 0 before `auth-service` and `core-api` are allowed to start.

## Partial startup — infrastructure only

```bash
docker compose up -d db cache-service message-broker object-storage
```

Use this when running application services on the host (see [Setup](./setup)).

## Partial startup — core services only (no monitoring)

```bash
docker compose up -d db cache-service message-broker object-storage db-migrator auth-service core-api frontend
```

## Rebuild one service

```bash
docker compose up -d --build core-api
```

## View logs

```bash
docker compose logs -f core-api          # stream one service
docker compose logs -f auth-service core-api frontend   # stream multiple
docker compose logs db-migrator          # one-shot check
```

## Check status

```bash
docker compose ps
```

Expected state once the stack is healthy:

| Service          | Status       |
| ---------------- | ------------ |
| `db-migrator`    | `Exited (0)` |
| `db`             | `Up`         |
| `cache-service`  | `Up`         |
| `message-broker` | `Up`         |
| `auth-service`   | `Up`         |
| `core-api`       | `Up`         |
| `frontend`       | `Up`         |
| `api-gateway`    | `Up`         |

## Restart a service

```bash
docker compose restart core-api
```

## Stop

```bash
docker compose down          # stop containers, keep volumes
docker compose down -v       # stop and delete all volumes (destroys data)
```

## Documentation portal

To rebuild the documentation portal image with fresh autogenerated content:

```bash
cd documentation
npm run docs:auto     # prepare:docs + docker build + docker compose up -d documentation
```

Or to regenerate only specific artifacts:

```bash
npm run gen:diagrams  # architecture diagrams
npm run gen:openapi   # OpenAPI MDX pages
npm run gen:typedoc   # TypeDoc frontend API pages
```

## Startup order detail

`db-migrator` is the gating dependency. From `docker-compose.yml`:

- `auth-service` and `core-api` both declare:

  ```yaml
  depends_on:
    db-migrator:
      condition: service_completed_successfully
  ```

- `db-migrator` itself depends on `db` being healthy.

If `db-migrator` exits non-zero, `auth-service` and `core-api` will never start in that compose session. Fix the root cause (usually a bad connection string or PostgreSQL not ready) and re-run `docker compose up -d`.
