# Repository Overview

> _If any detail here contradicts the code, trust the code — not this page._

## Top-level layout

```
DevHunt/
├── DevHunt.CoreApi/           # .NET 10 — main business logic API
├── DevHunt.AuthService/       # .NET 10 — JWT, OAuth, TOTP auth
├── DevHunt.Infrastructure/    # Shared library: DbContext, EF migrations, EnvLoader
├── DevHunt.DatabaseMigrator/  # .NET 10 console — runs EF migrations once and exits
├── DevHunt.DatabaseSeeder/    # .NET 10 console — optional dev data seeder
├── DevHunt.Analyzer/          # Roslyn analyzer for internal conventions
├── DevHunt.CoreApi.Tests/     # Core API unit/integration tests
├── DevHunt.AuthService.Tests/ # Auth Service tests
├── frontend/                  # Next.js 16 / React 19 web app
├── ml-service/                # Python / FastAPI — recommendations, AI
├── integration-gateway/       # Third-party integration routing service
├── notification-service/      # Push notification service
├── nginx/                     # Nginx config, Dockerfile, dev-cert script
├── documentation/             # Docusaurus portal (this site)
├── k8s/                       # Kubernetes manifests
├── monitoring/                # Prometheus and Grafana configuration
├── seaweedfs/                 # SeaweedFS object storage config
├── scripts/                   # Utility scripts
├── infrastructure/            # IaC (Terraform/Pulumi)
├── packages/                  # Shared packages
├── tests/                     # Integration and E2E test suites
├── .config/                   # dotnet-tools.json (swagger CLI, docfx — pinned)
├── docker-compose.yml         # Main compose file
├── docker-compose.override.yml.example  # Local dev secrets template
├── docker-compose.prod.yml    # Production compose overrides
└── DevHunt.slnx               # Solution file
```

## .NET services — where to look

### Core API (`DevHunt.CoreApi/`)

```
DevHunt.CoreApi/
├── Controllers/      # ~50 controllers grouped by domain
├── Services/         # Business logic, registered as DI services
├── Extensions/       # Startup extension methods (AddSignalRWithRedis, etc.)
├── Hubs/             # SignalR: ChatHub, NotificationHub
├── Middleware/        # Pipeline components
├── Program.cs        # Entry point
└── appsettings.json  # Baseline config (no secrets)
```

Entry point: `DevHunt.CoreApi/Program.cs`. for boot wiring details.

### Auth Service (`DevHunt.AuthService/`)

```
DevHunt.AuthService/
├── Controllers/      # Auth, token, OAuth, TOTP endpoints
├── Services/         # RefreshTokenService, JwtTokenService, MailKitEmailService, …
├── Program.cs        # Entry point
└── appsettings.json  # Baseline config (no secrets)
```

Entry point: `DevHunt.AuthService/Program.cs`.

### Shared infrastructure (`DevHunt.Infrastructure/`)

Contains `DevHuntDbContext`, all EF Core entity models, migrations, and the `EnvLoader` helper. Both `core-api` and `auth-service` reference this project.

### Database migrator (`DevHunt.DatabaseMigrator/`)

One-shot console app — runs `Database.MigrateAsync()` and exits.

## Frontend (`frontend/`)

```
frontend/src/
├── app/              # Next.js App Router: layouts, pages, route handlers
│   └── [locale]/     # Locale-prefixed route segments (next-intl)
│       ├── dashboard/
│       └── admin/
├── components/       # React components
├── hooks/            # Custom React hooks
├── lib/
│   ├── api/          # API client, schemas, adapters
│   ├── signalr.ts    # SignalR connection setup
│   ├── realtime/     # Real-time state management
│   └── store/        # Client-side state stores
└── middleware.ts     # Edge middleware: auth guard + i18n
```

Next.js config: `frontend/next.config.mjs`. Backend calls go through `/api/proxy-core/*` and `/api/proxy-auth/*` rewrites — the browser never holds direct service URLs.

```
documentation/

```
