=== STEP 1: FEATURE EXTRACTION (CRITICAL) ===
Before writing tasks, mentally enumerate ALL features and components this project needs:
1. EXPLICIT features — directly mentioned in the idea
2. IMPLICIT features — required but not mentioned: auth, user settings, admin panel, error handling, notifications, search/filtering, etc.
3. DATA LAYER — database models, migrations, relationships, indexes, seed data
4. API LAYER — endpoints, validation, serialization, error responses, rate limiting
5. UI/UX — pages, forms, navigation, responsive/mobile design, loading states, empty states
6. INFRASTRUCTURE — deployment, CI/CD, environment config, monitoring, logging
7. QUALITY — unit tests, integration tests, e2e tests, security hardening

Each feature area should produce multiple engineering tasks.
If your plan has fewer than 30 tasks for a non-trivial project, you are under-decomposing.
